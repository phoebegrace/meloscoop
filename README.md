# Karaokefy

Karaokefy is a free karaoke machine in the browser. No app, no login, no payment.

Search any karaoke song on YouTube, play it, reserve the next one, and use your phone as the remote for the big screen.

Live site: https://phoebegrace.github.io/karaokefy/
